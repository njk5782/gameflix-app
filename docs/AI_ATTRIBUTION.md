# AI Attribution

OpenAI ChatGPT/Codex assisted with substantial portions of the current
full-stack implementation, including frontend scaffolding, JWT integration,
subscription endpoints, catalog removal, automated tests, the Postman
collection, and CI security-scan configuration.

The project owner directed the product requirements, clarified that GameFlix is
a video game subscription service, selected the membership presentation,
reviewed the source, tested the browser workflows, ran Docker Compose, executed
the JUnit suite, and verified the API and failed-authentication cases in Postman.
The project owner also identified and requested corrections to the frontend
formatting, login message, token flow, membership selection, and invalid-token
test data.

The current uncommitted implementation should use a commit message beginning
with `[AI-assisted]`. A suitable message is:

```text
[AI-assisted] Complete secure GameFlix full-stack prototype
```

Earlier repository commits predate this attribution record and were not
rewritten. Their related AI assistance is disclosed retrospectively in
`PROMPT_JOURNAL.md`. Future commits containing substantial AI-generated code
will continue to use the `[AI-assisted]` prefix and will state when the output
was meaningfully reviewed or rewritten.
